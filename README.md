🎮 U CANT WIN

A fast-paced browser arcade game featuring shifting game modes, unpredictable challenges, and a test of survival.

🔗 **Play Now:** [ucantwin.netlify.app](https://ucantwin.netlify.app/)

### ✨ Features

* 🔄 Three dynamic game modes: Ship, Balloon, and Plane
* 🌀 Unexpected portals and changing gameplay
* 🎵 Procedurally generated soundtracks using Web Audio API
* ⏸️ Pause menu, progress tracking, and attempt counter
* 🌗 Dark and light themes
* 🏆 Saved high scores
* 📱 Keyboard and touch controls

### 🛠️ Built With

HTML5 • CSS3 • JavaScript • Canvas API • Web Audio API

### 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Play and see how long you can survive!

No installations, dependencies, or build tools required.

### 📂 Project Structure

* `index.html` — Landing page
* `play.html` — Game interface
* `game.js` — Game engine and mechanics
* `styles.css` — Styling and themes
* `script.js` — Landing page interactions
